# Кошелёк

Минималистичное PWA для учёта личных финансов на iPhone.
Полностью локально (localStorage), без бэкенда, регистрации и облака. Работает офлайн после первой загрузки.

## Возможности

- **Главная**: баланс со sparkline за 30 дней, доходы/расходы месяца, остаток за прошлый месяц, напоминания, долги, история по дням
- **Операции**: доход/расход, калькулятор (`1500+300*2`), своя клавиатура, категории с эмодзи + создание на лету, метки (обязательная / спонтанная / запланированная / регулярная), быстрые траты из истории
- **Напоминания**: регулярные ежемесячные платежи, появляются за 10 дней, цветовая шкала срочности, подтверждение оплаты создаёт расход
- **Аналитика**: навигация по месяцам, диаграмма (все / расходы / доходы), проценты по категориям, операции месяца
- **Отчёты**: живой отчёт текущего месяца (прогноз, норма сбережений, финансовое здоровье), история закрытых месяцев, автозакрытие 1-го числа
- **Долги**: «я должен» / «мне должны», влияют на баланс, история с таймлайном
- **Настройки**: тема, управление категориями, корректировка баланса, экспорт/импорт JSON, полный сброс удержанием 2,5 сек

## Стек

React 19 · TypeScript · Vite 7 (single-file build) · Tailwind CSS v4 · lucide-react · Service Worker (network-first)

## Разработка

```bash
npm install
npm run dev     # dev-сервер
npm run build   # сборка в dist/index.html (один файл)
```

## Деплой

Push в `main` → GitHub Actions собирает проект, штампует версию Service Worker
и публикует `dist/` на GitHub Pages.

Настройка Pages: `Settings → Pages → Source: GitHub Actions`.

При изменениях обновлять версию в `src/components/SettingsScreen.tsx` (блок «О приложении»).
